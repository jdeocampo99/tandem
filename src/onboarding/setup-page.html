Tandem setup

First run · a few quick steps. Tandem asks you to approve everything in the chat at the end, and you can change any of it later.

    Which providers may Tandem spend on?

    Found in your OMP models. Tandem only picks models from providers you tick.

    Which model does each job?

    Pick from the models you have. Each job shows an example setup to give you an idea; use whatever you have access to and like.

    JobModelThinking

    Which repos should Tandem work on?

    Search the repos Tandem found on this machine, or paste a path. Each one gets its own chat when you save. You can add more later.

      Skills every task gets

      Your personal skills and Claude Code plugin skills. Each repo's own skills load automatically, so they aren't listed. Tasks Tandem starts on its own, like fixing a failing PR, only get what you pick here. Most people pick a few.

        When Tandem runs into an issue

        Like a task that keeps failing or gets stuck. Should Tandem look into why?
